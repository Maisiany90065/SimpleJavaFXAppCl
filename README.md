# SimpleJavaFXApp

JavaFX Lab 1 project for Java 21, IntelliJ IDEA, Git and Gradle.

## Requirements
- JDK 21
- Gradle 9.7.1 or compatible
- IntelliJ IDEA
- Internet connection for the first Gradle build

## Run
Open a terminal in this project folder and run:

```bash
gradle run
```

## Git
```bash
git init
git add .
git commit -m "First JavaFX Lab Complete"
```

## Before submission
Replace `YOUR NAME` and `STUDENT NUMBER` in `HelloJavaFX.java` with your details.
